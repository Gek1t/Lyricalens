# 全网题库重塑方案：纯粹的「淘题入库工作台」与考场日历批次卡片

将「全网题库」弹窗从此前与主界面功能重叠的“第二做题大厅”彻底重塑为**专注于发现新题、批量勾选与一键入库的「淘题入库工作台（Question Acquisition Catalog）」**，消除冗余模块与同质化的头版大图，打造专属的**考场日历批次卡片（Exam Calendar Batch Cards）**空间层次。

## 1. Overview & Core Concept

- **What It Does**：作为雅思主界面的**外部题源补充器（Question Ingestion & Curation Drawer）**，专门负责将「2026 当季最新实考机经」与「全网检索装订的专项/冷门卷宗」批量或按篇收入用户的「自选馆藏」。
- **Target Audience / Persona**：希望快速浏览近期亚太/大陆考场回忆、识别哪些场次含首发新题或高频旧题复现，并将目标篇章一键加入个人题库备考的雅思考生。
- **Key Value**：
  1. **职责边界清晰**：主界面管“练题与管理”，弹窗管“淘题与入库”，零功能重复。
  2. **层次分明且不雷同**：通过「台历日期存根 + 象牙纸题单 + 底部入库汇总栏」建立属于“选题目录”的专属纸质档案美感。

## 2. User Experience & Visual Design

### Key User Flows
1. **进入淘题工作台（默认直达「考季机经」）**：
   - 顶部左上方为「`← 返回`」（回到雅思主界面），正中为「`淘题与新题入库`」，右侧为清爽的「`阅读 · 听力`」切换。
   - 刊头导航仅保留 **「考季机经」** 与 **「全网搜卷」** 两个标签，彻底告别四标签拥挤感。
2. **浏览「考季机经」考场日历批次卡片**：
   - 顶部工具条左侧为内凹式考区筛选槽（`全部考区 / 亚太 / 大陆 / 全球`），右侧为「`仅看未入库`」过滤开关与机经搜索框。
   - 每一场实考呈现为一张极具辨识度的**「考场日历批次卡片（Exam Calendar Batch Card）」**：
     - **左侧 / 顶部台历存根区（Calendar Stub）**：以暖砂色（`#F3EEE4`）底纹呈现大号衬线数字日期（如 `21` / `MAR · 周六`）、考区印章（`亚太考区`）、新题首发/旧题复现状态说明，以及醒目的 **「`+ 整场入库 (3篇)`」** 按钮（若全部已收录则显示 `✓ 本场已全数入库`）。
     - **主体象牙纸题单区（Ivory Paper Batch List）**：在 `#FDFBF7` 象牙白纸面上分列 `P1 / P2 / P3`（或听力 `S1–S4`）三篇考题，每行展示**中英双语题目、学科色彩圆点、首发新题/剑雅母题溯源说明与题型配比（如 `判断 + 填空 · Band 6.5`）**。
     - **单篇点选入库**：点击任意单篇行或右侧勾选框，即刻切换 `✓ 已入库` / `+ 入库` 状态，并伴有轻盈的触感反馈。
3. **使用「全网搜卷」检索装订并入库**：
   - 顶部为内嵌于象牙纸面的**档案检索栏**与常用检索词（无冗余大图堆砌）。
   - 未检索时下方展示「高频专题题集推荐（可一键整套入库）」；检索后展示装订好的标准套卷清单，支持单篇勾选入库或「`+ 整卷一键入库`」。
4. **底部馆藏同步栏（Collection Dock）**：
   - 当用户在弹窗内勾选入库题目时，底部浮现温润的暖纸色汇总条：`自选馆藏已收录 X 篇阅读 · Y 篇听力`，右侧提供「`完成并返回主界面`」按钮，形成完整的“淘题 → 入库 → 回主界面练题”闭环。

### Visual Identity & Theme
- **Aesthetic Direction**：**典藏考场台历与选书目录（Archival Exam Almanac & Acquisition Catalog）**——与主界面共享暖米白纸张基因，但采用“台历存根 + 勾选清单”的目录学排版，一眼即可区分“这里是在选书入库，而非做题大厅”。
- **Color Palette & Mood**：
  - **画布底色（60% Canvas）**：暖米白宣纸底色 `#FAF7F2`（暗色模式 `#0C0C0E`）。
  - **批次卡片表面（30% Structural Surfaces）**：悬浮象牙白纸面 `#FDFBF7` + 暖砂色台历存根区 `#F3EEE4` + 细腻墨线 `border-stone-900/[0.08]`。
  - **点缀色（10% Curatorial Accents）**：典藏松石绿 `#516050`（表示“已入库 / 勾选完成”）、琥珀赭石 `#B45309`（标注“新题首发 / 高频母题复现预警”）。
- **Typography & Hierarchy**：
  - **台历日期存根**：高对比度衬线数字（`font-serif-luxury text-2xl font-bold tabular-nums`）配等宽月份与星期。
  - **篇章主标题**：粗体中文课题名（`15px font-bold text-stone-900`）配衬线斜体英文原名（`font-serif-luxury italic text-xs text-stone-500`）。
  - **零胶囊元数据（Zero-Pill Metadata）**：学科分类、新旧题属性、题型组合（如 `生态学 · 2026首发新题 · 判断+填空`）全部采用无框印刷体与 `·` 分隔符呈现。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1：彻底砍掉「真题馆」与「馆藏」两个重复 Tab**
  - *Chosen Approach*：弹窗导航仅保留「考季机经」与「全网搜卷」，并将默认打开的 Tab 设为「考季机经」。
  - *Why*：主界面（`IELTSHubView`）本身就已经拥有完整的「剑桥真题（C4–C20）」和「自选馆藏」视图。在弹窗里再放一遍不仅造成严重的视觉雷同，还会让用户困惑“到底在哪做题、在哪加题”。
- **Decision 2：采用「考场日历批次卡片」替代主界面的学科头版大图**
  - *Chosen Approach*：用左/上侧带日期存根（Date Stub）的批次档案卡封装每一场考试（如 `03月21日 · 亚太考区`、`03月14日 · 大陆考区`），卡片内直接呈现 P1/P2/P3 的入库勾选行。
  - *Why*：考季机经的核心维度是**“考试时间批次 + 考区 + 哪篇是新题/哪篇是旧题”**。台历存根式卡片既赋予了界面丰富的纸张层次感（`#FAF7F2` 画布 + `#F3EEE4` 台历存根 + `#FDFBF7` 象牙白题单），又完全不同于主界面的单篇大图推荐。
- **Decision 3：整行点击即切换“入库/移出”状态**
  - *Chosen Approach*：在淘题工作台中，点击任意篇章行或右侧勾选框直接触发入库/取消入库，不再直接打断选书流程跳去全屏做题。
  - *Why*：符合用户“一次逛完近期机经、勾选几篇感兴趣的题目收入囊中，再回主界面安心练习”的真实动线。

### Data Model & State
- **Active Tab State**：精简为 `'live-feed' | 'web-search'`，默认值为 `'live-feed'`。
- **Filter State**：
  - `skillFilter`（`'reading' | 'listening'`）：统一控制「考季机经」与「全网搜卷」展示阅读篇章或听力 Section。
  - `timelineRegionFilter`（`'all' | 'APAC' | 'Mainland' | 'Global'`）：按考区筛选考场日历批次。
  - `onlyUnsaved`（`boolean`）：支持一键过滤掉已收录的篇目，方便快速淘新题。
- **Ingestion State (`savedPassageIds` / `savedListeningIds`)**：与主界面 `customPassages` 及 `customListening` 实时双向绑定，支持单篇增删与整场/整卷批量入库去重。

### Interactive Component & State Mapping
- **单篇行点击 (`handleTogglePassageSave` / `handleToggleListeningSave`)**：点击行或右侧勾选按钮时，若未收录则调用 `handleAddPassage` 并显示轻提示；若已收录则可点击移出，勾选框在空心圆框（`+ 入库`）与松石绿实心徽标（`✓ 已入库`）间平滑切换。
- **整场/整卷批量入库 (`handleSaveSessionBatch` / `handleImportEntireVolume`)**：遍历该考场批次下所有未入库的篇章并一次性写入本地馆藏状态，按钮自动变为 `✓ 本场已全数入库`。
- **底部馆藏汇总栏 (`Collection Sync Bar`)**：实时统计当前已收入馆藏的阅读/听力总数，点击「完成并返回主界面」直接关闭弹窗回到主界面自选馆藏。
