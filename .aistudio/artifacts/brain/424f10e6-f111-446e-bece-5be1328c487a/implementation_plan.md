# 雅思专区大厅：极简减负与中文主题导读改造方案

针对当前进入雅思专区时「顶部按钮堆叠过多、层级混乱」以及「单篇文章只有纯英文标题与代号，无法一眼看懂内容」两大核心痛点，结合您的反馈，制定以下创新精简与信息透传方案：

---

### 一、 顶部操作区创新减负：从「5 层按钮堆叠」压缩为「1 栏极简中枢」

目前页面从上到下足足堆了 5 层按钮（顶栏 3 个模式按钮 + 书架标题与全网搜卷按钮 + 阅读听力切换 + 搜索框 + 卷册胶囊筛选栏）。我们将通过三项创新交互将其彻底瘦身：

1. **「本地检索 + 全网搜卷 + 自定义出题」三合一智能命令舱（Unified Omni-Search Bar）**
   - **砍掉独立的「全网搜卷」绿胶囊按钮**，同时**砍掉顶栏左侧常驻的「自定义导入 / 生成练习」冗余按钮**。
   - 首屏顶部只保留**一个高质感毛玻璃智能搜索栏**：
     - **平时状态**：左侧为搜索输入区（支持搜中英文主题，如“巴黎农业”、“网球拍”），右侧内嵌一枚极简的**「+ 搜全网 / 自建」灵动入口（Command Trigger）**。
     - **联动交互**：当用户在搜索框输入关键词但本地无匹配时，下拉面板直接一键触发「去全网搜卷」或「用该主题 AI 生成练习」；点击右侧灵动入口也可随时唤出轻量操作面板（全网真题库检索 / 粘贴外刊导入 / 词单定制生成）。
2. **「阅读 / 听力」与「卷册切换」同层合一（取消独立卷册胶囊行）**
   - 取消原本占满一行的 `全部卷册 · Cambridge 18 · Cambridge 17...` 横向滚动胶囊条。
   - 将左侧**「学术阅读 / 官方听力」分段滑块**与右侧**「卷册快速跳选器（全部卷册 ▾）」**合并在同一水平行内，首屏操作区高度直接缩减 50% 以上，视线第一时间聚焦在真题内容本身。

---

### 二、 微观文章卡片升级：中英双语主次分明，一秒看懂文章内容

解决「满屏英文标题和代号（T1 P1 · Band 7.0），不知道文章讲什么」的问题：

1. **为全量剑桥阅读与听力真题建立「中文核心主题译名」映射与字段**
   - 为题库内所有剑雅真题补充地道、直观的**中文核心主题（`titleZh`）**，例如：
     - *Urban Farming in Paris* → **巴黎屋顶的城市农业探索**（农学与城市生态）
     - *The Step Pyramid of Djoser* → **古埃及左塞尔阶梯金字塔考古**（考古与建筑史）
     - *Bats to the Rescue* → **马达加斯加农业救星：食虫蝙蝠**（生态保护）
     - *The Evolution of Modern Tennis Rackets* → **现代网球拍的材料科技演进**（材料科学）
     - *Stonehenge* → **巨石阵建造之谜与历史演进**（历史考古）
     - *Living with Artificial Intelligence* → **人类如何与人工智能共存**（科技与伦理）
     - *An Ideal City* → **达·芬奇笔下的文艺复兴理想城市**（城市规划史）
     - 以及所有听力 Section（如 *Harbor Eco-Tours & Kayak Hire* → **海港生态游与皮划艇预订咨询**）。
   - 同时支持全网搜卷新增文章自动提取/生成中文核心主题。
2. **卡片微观排版重构（中文主题先行，英文原题相辅）**
   - **今日推荐大卡（Featured Card）**：
     - **第一视觉焦点**：醒目展示**中文核心主题大标题**（如「**巴黎屋顶的城市农业探索**」），紧随其后展示典雅衬线体英文原题 *Urban Farming in Paris*。
     - **极简角标**：右上角仅保留干净的 `剑18 · T1 P1` 与词单命中提示，彻底告别繁琐参数。
   - **下方剑桥分卷清晰列表（Volume Rows）**：
     - 左侧保留精致的 `P1 / P2 / P3`（或听力 `S1~S4`）篇章序号徽章；
     - 中间主标题直接采用**「中文核心主题」**（一眼看懂讲什么），副标题单行展示**「英文原题 · 命中词数 / 难度」**；
     - 点击整行即刻进入模考，干净利落。
